              How detection works
              
Each name is a text prompt for SAM 3, run on every camera. A camera's masks are lifted with its depth
                (edges and the table left out) and joined in 3D with the other cameras': one object per thing, in its own
                colour. What only one camera finds while the others see that spot is dropped. Scene graph above the
                3D view shows only the objects, their boxes and, when the pose tracking has one, their frame; the
                Graph tab lists them and how they relate (on, in, next to). Precise names work best
                (ceramic mug, black machine). Detection and pose tracking each run their own model.

            

            

              How scanning works
              
Each name is the segmenter's text prompt. Objects without a mesh: Scan, then move the wrist cameras
                (teleop or by hand) to views of the objects from all sides, Capture view at each, Finish: a mesh per
                object, tracking starts at the scanned poses (Point cloud and Object poses start by themselves).
                Automatic: the arms move on their own instead. Objects with a mesh are not scanned again; the tracking
                finds them ( scans one again).

              How calibration works
              
Board lying still on the table; bring each arm (teleop) to a pose where its wrist camera sees it. The arm then
                probes and drives to 8 views around the board by itself. Then move the board to another spot the middle camera
                sees and Add placement: 2–3 placements spread over the workspace fit it far better than one. With the
                point cloud running, the clouds fine-tune the result.
